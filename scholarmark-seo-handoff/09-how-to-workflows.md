# Student How-To Workflows

These workflows can be reused in blog posts, onboarding, emails, support docs, and in-product education.

## Workflow 1: Source Base First

Use for:

- `AI writing with sources`
- `source grounded AI writing`
- `thesis source organization`

Steps:

1. Create a project for the assignment.
2. Upload or paste the sources you are allowed to use.
3. Add web clips with URL, date, author, and surrounding context.
4. Sort sources into simple states: to read, skimmed, useful, cited, rejected.
5. Search across the project before asking AI to draft.
6. Save passages that may become evidence.
7. Build the outline from saved evidence, not from a blank page.

Message:

The source base is the foundation. The draft comes later.

## Workflow 2: Quote Bank Before Draft

Use for:

- `how to build a quote bank`
- `hallucinated quotes AI`
- `quote verification`

For each quote, save:

- exact passage text
- source title
- author
- page, section, paragraph, or location
- surrounding context
- why it matters
- possible claim it supports
- citation note
- verification status

Verification statuses:

- exact quote found
- context checked
- citation metadata checked
- paraphrase only
- not usable

Message:

Do not let a perfect-sounding quote enter the draft until you can find it in the source.

## Workflow 3: Evidence-To-Outline

Use for:

- `thesis outline from sources`
- `how to start a thesis`
- `capstone writing tool`

Steps:

1. Group quote-bank entries by theme.
2. Turn each theme into a working section.
3. Write one claim for each section.
4. Attach two to four evidence items to each claim.
5. Add one "gap" note for each weak section.
6. Decide which sections need more reading before drafting.

Message:

A strong outline is not a list of topics. It is a map of claims and evidence.

## Workflow 4: Citation Verification

Use for:

- `citation verification AI`
- `AI citations research papers`
- `verify citations AI`

Steps:

1. Confirm the source exists.
2. Confirm author, title, publication, date, and DOI or URL.
3. Confirm the source is acceptable under assignment rules.
4. Open the source and locate the exact passage or section.
5. Check whether the source supports the claim.
6. Check whether direct quotes match exactly.
7. Format the citation in the required style.
8. Re-check final bibliography before submitting.

Message:

Citation formatting is not the same as citation verification.

## Workflow 5: Responsible AI Process Record

Use for:

- `AI academic integrity writing`
- `prove I wrote my essay`
- `AI writing tool cheating`

Keep:

- assignment instructions
- course AI policy
- source list
- notes and annotations
- outline versions
- AI prompts used for allowed support
- draft history
- final verification checklist

Message:

The safest academic AI workflow is transparent, source-grounded, and easy to explain.

## Workflow 6: Summer Thesis Head Start

Use for:

- `/summer`
- `summer thesis planning`
- `senior thesis plan`

8-week structure:

1. Week 1: choose a broad topic and collect starter sources.
2. Week 2: build source base and skim for repeated debates.
3. Week 3: draft two to three possible research questions.
4. Week 4: build quote bank and context notes.
5. Week 5: create working outline from evidence.
6. Week 6: draft one section or literature review slice.
7. Week 7: identify gaps and counterarguments.
8. Week 8: verify quotes/citations and create a fall plan.

Message:

Summer progress does not have to mean finishing the thesis. It means starting fall with sources, quotes, a question, and a plan.
